# Operational Source Inventory

**Phase 9 — Operational Domain Design**

## Purpose

This document defines every operational source entity used by the Field Operations Intelligence Platform.

It establishes:

- Business purpose
- Grain
- Business key
- Primary key
- Foreign keys
- Core relationships
- Ownership
- Refresh expectations

This document defines the operational source model only.

Role-playing dimensions, star-schema design, and analytical reshaping occur later in the Gold layer.
